# RELEASE v1.2.0

## Summary

- `v1.2.0` focuses on making Skill Flow easier to organize and use day to day on desktop.
- You can now organize groups with tags, browse more clearly in the menu bar, and keep agent displays aligned with your own preferences.
- This release also expands macOS downloads so users can install the app with Apple Silicon, Intel, or universal packages.

## Highlights

### 1. Group tags for faster organization

- Groups can now be tagged, making it easier to sort and recognize related skill collections.
- Tag interactions across the desktop app are more complete and more consistent.
- Group cards now surface tags more clearly, including in compact menu bar cards.

### 2. Better desktop browsing and detail views

- Group cards and detail views are easier to scan during everyday use.
- Agent display can be customized so cards and detail pages better match each user’s preferred order and visibility.
- Detail content now behaves more consistently across supported languages, including the group file tree view.

### 3. More stable interaction flows

- Desktop selection, refresh, and save states are more predictable during repeated use.
- Source discovery and refresh behavior are more reliable when working with existing local content.
- Import and update flows have been refined to reduce confusing intermediate states.

### 4. More download options for macOS

- macOS releases are now available as:
  - Apple Silicon (`arm64`)
  - Intel (`x86_64`)
  - Universal
- Each release includes both `.dmg` and `.zip` downloads, plus a checksum file.

## User-visible changes

- The menu bar view is more useful as a quick control surface instead of only a compact summary.
- Group organization is stronger because tags, card state, and detail state now work together more naturally.
- Installation is simpler on different Mac hardware because users can choose the package that matches their machine.
