# Issue tracker: Local Markdown

Issues for this repo are tracked as local Markdown files under `.scratch/issues/`.

## Conventions

- Each issue or spec should live in its own feature directory under `.scratch/issues/`.
- Keep the issue body, status, and triage label in Markdown so the record remains inspectable locally.
- Do not use GitHub, GitLab, or another remote tracker for this repo's engineering-skill workflow.
- The `.scratch/issues/` directory is ignored by Git because these records are local-only.

## When a skill says “publish to the issue tracker”

Create or update the appropriate Markdown issue under `.scratch/issues/`.

## When a skill says “fetch the relevant ticket”

Read the matching Markdown issue under `.scratch/issues/`.
